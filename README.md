# Ketan Pramod Behare — Portfolio

A personal portfolio website for Ketan Pramod Behare, a first-year Electronics and Telecommunication Engineering (EXTC) student.

## Overview

The portfolio presents the owner's profile, education, skills, EXTC interests, projects, certificates, resume, and contact information.

## Built with

- HTML
- CSS
- JavaScript
- Google Fonts (loaded externally)

The website is currently delivered as a single-page HTML file. Images and other assets embedded as data are contained in `index.html`; no build step or package installation is required.

## Run locally

Open `index.html` in a modern web browser.

## Deploy with GitHub Pages

1. Create a GitHub repository (for example, `ketan-portfolio`).
2. Upload `index.html` and `README.md` to the repository's root directory.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment completes, the site will be available at `https://<your-github-username>.github.io/ketan-portfolio/`.

## Notes

- Google Fonts requires an internet connection; fallback fonts are used if it cannot load.
- The contact form uses the visitor's email application (`mailto`) rather than a server-side form service.
- Review the contact details and any personal information in `index.html` before making the repository public. A public repository makes its source code and embedded assets visible to everyone.
